# Miss Shreya Apology Website

A small romantic, pink-and-cream landing page built with HTML, CSS, and vanilla JavaScript.

## Project structure

- `index.html` — page structure and letter content
- `css/style.css` — colors, layout, responsive rules, and animations
- `js/script.js` — letter toggle and floating-heart interaction
- `assets/images/` — place any project images here
- `assets/music/` — place optional audio files here

## Run locally

1. Open this folder in Visual Studio Code.
2. Open `index.html` with the Live Server extension, or open the file directly in a browser.
3. Click **Open My Little Letter** to reveal the letter.

The `assets/images` and `assets/music` folders are intentionally empty for now. Add only photos or audio that you have permission to use.
